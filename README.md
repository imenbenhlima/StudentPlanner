# Étudiant

A comprehensive student companion application built for Android. It allows students to manage their courses, timetable, assignments, notes, grades, and reminders effectively.

## Features

- **Courses Management**: Keep track of your courses including name, coefficient, and type (Cours, TD, TP, CI).
- **Timetable**: Organize your weekly schedule.
- **Assignments**: Track your homework and due dates.
- **Notes**: Take and link notes to specific courses.
- **Grades**: Log your grades and automatically calculate your weighted average.
- **Timers/Reminders**: Get countdowns for important dates (holidays, school starts) and set custom reminders.
- **Dark/Light Theme**: Support for system default, dark, and light themes.
- **Semester Management**: Manage your data by academic semesters.

## Tech Stack

- **Platform**: Android (minSdk 26, targetSdk 34)
- **Language**: Java / Kotlin (Source Compatibility 17)
- **UI**: XML with ViewBinding, Material Components, ConstraintLayout
- **Architecture**: MVVM (ViewModel, LiveData)
- **Navigation**: Android Jetpack Navigation Component
- **Database**: Room Database
- **Preferences**: AndroidX Preference library

## Getting Started

### Prerequisites

- Android Studio (Latest stable version recommended)
- Android SDK (API 34)

### Installation

1. Clone the repository:
   ```bash
   git clone [<repository-url>](https://github.com/imenbenhlima/StudentPlanner)
   ```
2. Open the project in Android Studio.
3. Sync the project with Gradle files.
4. Run the app on an emulator or a physical device.
